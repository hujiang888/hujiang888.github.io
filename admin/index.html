SIGN IN

用 GitHub Token 登录

后台不需要额外服务器：它通过 GitHub Contents API 读取和写入内容。 Token 只保存在当前标签页的 sessionStorage，关闭页面即清除。

如何生成 Token？
  1. 打开 GitHub Fine-grained tokens，点击 Generate new token。
  2. Repository access 只选择 hujiang888/hujiang888.github.io。
  3. Permissions → Contents 设为 Read and write。
  4. 生成后复制到上方输入框。Token 只用于本页写入，不会上传到其他地方。

如果使用经典 Token，请勾选 repo 权限。
